# 0005: Publish under Apache 2.0

- Status: Accepted
- Date: 2026-09-07

## Context

The author's default for published work is a noncommercial license. That default is decided per
repository, and the question is always who the audience is.

Here the audience is whoever has Shield Event Monitoring, which is Salesforce customers on paid
editions, plus Developer Edition orgs where the feature is free. A noncommercial license would
leave the tool readable by nearly everyone who needs it and usable by almost none of them.

## Decision

Apache License 2.0, with the notice in `LICENSE` and `NOTICE` and no per-file headers.

## Consequences

- Anyone can use it at work, which is the only place event log analysis happens.
- Contributions arrive under the same license, so no contributor agreement is needed, and
  selling a commercial license later would need the agreement of every contributor.
- The patent grant comes along. It costs nothing here and answers a question a cautious legal
  team asks about any tool that touches audit data.
